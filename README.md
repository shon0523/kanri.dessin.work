# C STUDIO Reserve

C STUDIO セルフ写真館フランチャイズ向け **予約管理 SaaS プロトタイプ UI**。
加盟店オーナーが自店舗の予約・ブース・メニュー・事前決済を管理し、本部が FC 全体を統括できる予約基盤の管理画面です。

RESERVA のような白基調・淡いグレー背景・カード型レイアウト・左サイドバーの清潔な業務システム UI を参考に、C STUDIO 独自の FC 予約管理システムとして再設計しています。

## 技術スタック

- React 18（Vite）
- Tailwind CSS 3
- モックデータ（API 接続なし・フロントエンドプロトタイプ）

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run preview  # ビルド結果のプレビュー
```

## 画面構成（左サイドバーで切替）

1. ダッシュボード — KPI、直近予約、ブース稼働、人気メニュー、本部お知らせ、Stripe ステータス
2. 予約管理 — 一覧・フィルター・予約詳細モーダル
3. ブース・スペース管理 — 箱（リソース）型予約。追加モーダル / 各種トグル
4. メニュー管理 — 大/中/小メニュー 3 階層タブ。**表示所要時間と実予約時間を分離**
5. 予約サイト設定 — 公開設定・予約導線（メニュー/ブース/日時から選ぶ）
6. **事前決済設定**（初期表示）— ステータスカード、ON/OFF、決済方法、メニュー別設定、キャンセル料、返金設定、保存フッター
7. **Stripe 接続設定** — 接続/未接続/審査中/追加情報/エラーの各状態、テストモード
8. 売上管理 — KPI、日別グラフ、メニュー別/ブース別売上、決済一覧
9. 顧客管理 — 一覧・顧客詳細モーダル（予約/決済/キャンセル履歴）
10. 店舗設定 — 店舗情報・権限管理・スタッフアカウント

> 最初に表示される画面は **事前決済設定** です。そこから Stripe 接続・メニュー別決済・キャンセル料・返金設定へ自然に遷移できます。

## 予約ロジック（UI で表現）

「メニュー」ではなく **箱＝ブース・スペースの時間枠を押さえる** 予約方式。
複数ブース登録、メニューごとに異なる必要時間枠、表示時間と実予約時間の分離、必要リソース割当、二重予約防止、自動割当 / 指名予約の選択を UI 上で表現しています。

## 想定ユーザー

FC 本部管理者 / 加盟店オーナー / 店舗スタッフ。本プロトタイプは加盟店オーナー向け画面を中心に、本部 SaaS としての拡張性も意識した構成です。
